월별 기록 개별 보관

♡ 10월 한눈에 보기

10월은 원본 기록을 유지하며, 다른 달은 새로 입력할 수 있습니다. 입력된 시간을 바꾸면 계산 결과도 갱신됩니다.

10월 공휴일 빨간색 표시

전체 휴무에는 주간 휴무와 공휴일에 따른 휴무가 함께 포함됩니다. 동일한 날짜를 두 번 세지 않습니다.

공휴일은 월별로 등록·수정할 수 있습니다. 공휴일에 근무한 날은 추가 근무시간 합산에서 제외합니다. 대체공휴일도 날짜별로 등록해 주세요.

♡ 월별 휴무와 추가 근무시간

휴무는 6일 근무 후 쉬는 날과 공휴일에 따른 휴무를 합산합니다. 공휴일 근무일은 별도로 표시하며, 추가 근무시간은 휴무일 및 공휴일을 제외한 근무일에 대해서만 계산합니다. 하루 기준 실근로는 7시간 40분입니다.

주간별 휴무 확인 · 6일 근무 후 1일 휴무

전월에서 넘어온 추가 근무시간

9월 말 기준으로 확인된 잔여시간이 있다면 입력하세요. 값이 없으면 0으로 두되, 확정되지 않았다는 안내가 표시됩니다.

♡ 휴무일의 종류 확인

휴무는 주간 휴무와 공휴일 휴무, 연차 등을 합한 실제 사용 총량입니다. 공휴일에 쉰 날은 휴무일 수에서 중복 계산하지 않습니다. 미분류 휴무는 추가 근무시간에서 자동 차감되지 않습니다. 주간 휴무는 실제 6일 근무 후 쉬는 흐름을 전후 달과 함께 확인합니다. 공휴일에 쉰 날은 다시 더하지 않습니다.

날짜기존 기록휴무 종류차감·잔여 계산수정

연차·월차는 회사에서 인정된 발생일수를 따로 입력해야 잔여가 계산됩니다. 공휴일 대체휴무도 인정된 발생 일수를 입력한 만큼만 계산합니다.

발생일수를 아직 모른다면 0으로 두고 정산표의 ‘확인 필요’ 안내를 참고하세요.

♡ 10월 날짜별 근무 달력

원본에 기재된 출근 배정·퇴근 입력값과 휴무를 그대로 표시합니다. 공휴일은 빨간 글씨로 확인할 수 있어요.

※ 달력의 출퇴근시간은 입력된 값이며, 확정된 실제 근무시간임을 뜻하지 않습니다. 날짜를 누르면 기록을 수정할 수 있습니다.

♡ 10월 상세 근무 기록 · 31일 전체

사진에 보이는 날짜별 내용과 원본 백업을 상세히 옮겼습니다. 출근 배정, 입력된 출퇴근, 출근 확인 시각, 점심 20분·휴게 60분 처리, 실근로, 메모를 모두 확인할 수 있습니다.

날짜기록 메모일정출근 배정입력 출근출근 확인입력 퇴근실근로점심 20분휴게 60분추가 근무시간*휴무 구분수정

* 추가 근무시간: 공휴일과 휴무일 제외, 실제 입력된 출퇴근·휴게 선택을 기준으로 하루 7시간 40분과 비교한 차이입니다. 음수도 숨기지 않고 표시합니다. 출근 확인 시각은 반드시 실제 근로 시작시각과 같지는 않습니다.

♡ 시간표 사진과 기록 비교

사진은 스크롤을 따라오며, 날짜별 실제 입력내용을 확인할 수 있습니다. 자동 예상시간은 기록의 사실 여부와 별개입니다.

♡ Firebase 실시간 동기화

PC와 휴대폰에서 같은 계정으로 로그인하면 선택한 월의 기록을 공유합니다. 처음 연결할 때는 자동 업로드하지 않으며, 기존 서버 기록을 불러올지 직접 선택합니다.

계정은 Firebase 콘솔 → Authentication → 사용자에서 먼저 생성하세요. 이 페이지에서 누구나 회원가입하는 기능은 제공하지 않습니다.
