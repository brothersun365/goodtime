Firebase Storage 보안 설정

로그인한 본인만 자신의 시간표 사진에 접근하도록 보관하세요.

Firebase Console → Storage → Rules에 아래 규칙을 적용할 수 있습니다. 공개 쓰기 규칙은 사용하지 마세요. 이 HTML을 Firebase Hosting에 배포하면 로그인과 이미지 저장을 안정적으로 이용할 수 있습니다.

rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /users/{userId}/schedule/{allPaths=**} {
      allow read, write: if request.auth != null
                         && request.auth.uid == userId;
    }
  }
}

Firebase Storage 사용 가능 여부와 요금제 조건은 프로젝트 설정에 따라 다릅니다. 사이트는 Firebase에 로그인하기 전에는 기존 로컬 이미지를 표시합니다.
