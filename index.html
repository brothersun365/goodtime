☁ Firebase 클라우드 동기화

기존 good-time1004 프로젝트 사용. 로그인하면 클라우드 기록을 자동으로 읽어옵니다. 접속할 때마다 확인창이 뜨지 않으며, 불러오기만으로 클라우드를 덮어쓰지 않습니다. 날짜를 직접 수정한 내용만 해당 날짜에 반영합니다.

로그인하지 않아도 로컬 기록을 사용할 수 있습니다.

클라우드와 로컬에 같은 날짜의 기록이 다르면 클라우드 기존 기록을 우선 유지하고, 복구용 백업을 브라우저에 보관합니다. 현재 편집 중인 기록은 변경사항을 보호합니다. '로컬 전용 기록 업로드'는 클라우드에 해당 날짜가 없는 기록만 업로드합니다.

모바일 · PC에서 로그인이 안 될 때 확인할 사항

같은 이메일/비밀번호를 입력해도 로그인되지 않는다면 Firebase 콘솔 → Authentication → Sign-in method에서 이메일/비밀번호 제공업체가 켜져 있는지 확인해 주세요. Settings → Authorized domains에 brothersun365.github.io가 등록되어 있는지도 확인해 주세요. 사용자 계정은 Firebase 프로젝트 good-time1004의 Authentication → Users에 등록되어 있어야 합니다. 이 사이트는 새 계정을 자동 생성하거나 비밀번호를 변경하지 않습니다. 로그인 버튼 아래 오류 코드가 표시되며, 모바일 시크릿 모드나 브라우저의 쿠키/사이트 데이터 차단 설정은 로그인 유지에 영향을 줄 수 있습니다.

Firestore 보안 규칙 확인
rules_version = '2';
service cloud.firestore {
 match /databases/{database}/documents {
  match /users/{userId}/diaries/{month} {
   allow read, write: if request.auth != null && request.auth.uid == userId;
  }
 }
}

프로젝트의 다른 규칙을 덮어쓰지 말고 기존 규칙에 추가하세요.
