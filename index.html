☁ Firebase 클라우드 동기화

기존 good-time1004 프로젝트에 이메일/비밀번호로 로그인하면 본인 계정의 기록만 Firestore에 저장합니다. 브라우저에도 즉시 저장되며 인터넷이 연결되면 클라우드에 반영됩니다.

로그인하지 않아도 로컬 기록은 사용할 수 있습니다. 최초 연결 시에는 클라우드에 기존 데이터가 있으면 불러오기 전에 확인합니다.

Firestore 보안 규칙 확인
rules_version = '2';
service cloud.firestore {
 match /databases/{database}/documents {
  match /users/{userId}/diaries/{month} {
   allow read, write: if request.auth != null && request.auth.uid == userId;
  }
 }
}

Firebase 콘솔에서 이메일/비밀번호 로그인을 활성화하고 위 규칙을 프로젝트의 다른 컬렉션 규칙과 합쳐 적용해야 합니다. 전체 규칙을 덮어쓰면 다른 앱이 중단될 수 있습니다.

♡ 기록 저장 및 백업

입력하면 이 브라우저에 자동 저장됩니다. 브라우저 데이터를 삭제하거나 다른 기기에서 접속하면 기록이 사라질 수 있으니 JSON 백업 파일도 꼭 저장해 주세요.

로컬 저장은 인터넷 없이도 작동합니다. Firebase 로그인과 엑셀·PDF·Word 파일 생성은 인터넷 연결이 필요할 수 있습니다. GitHub Pages(HTTPS) 배포를 권장합니다.
