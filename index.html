관리자용: Firebase 데이터·사진 보안 규칙

Firebase Firestore + Storage 보안 설정

로그인한 본인만 자신의 시간표 사진에 접근하도록 보관하세요.

Firebase Console → Storage → Rules에 아래 Storage 규칙을 적용하세요. 공개 쓰기 규칙은 사용하지 마세요. 이 HTML을 Firebase Hosting에 배포하면 로그인과 이미지 저장을 안정적으로 이용할 수 있습니다.

rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /users/{userId}/schedule/{allPaths=**} {
      allow read, write: if request.auth != null
                         && request.auth.uid == userId;
    }
  }
}

Firestore Database → Rules에는 아래 별도 규칙을 적용하세요.

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/private/{documentId} {
      allow read, write: if request.auth != null
                         && request.auth.uid == userId;
    }
  }
}

Firebase Storage 사용 가능 여부와 요금제 조건은 프로젝트 설정에 따라 다릅니다. 사이트는 Firebase에 로그인하기 전에는 기존 로컬 이미지를 표시합니다.

기록 백업

근무기록 및 브라우저에 있는 사진을 별도 파일로 백업할 수 있습니다. Firebase에 연결한 경우 기록과 클라우드 사진은 각각 온라인 보관됩니다.

Firebase 로그인 시 근무기록은 Firestore에 자동 저장되며 주간 사진은 Storage에 저장됩니다. 연결이 없으면 이 브라우저에만 보관됩니다. 정기적인 JSON 백업도 권장합니다. Firebase 사진은 JSON 백업에 포함되지 않습니다.
